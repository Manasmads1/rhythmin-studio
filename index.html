Studio timeline

Every knob does something.

The studio is not a mock. Playback is real Web Audio, the sequencer is Tone.js, the synth has an actual ADSR + resonant lowpass. Nothing is animation-only.

01 16-step drum sequencer with per-cell velocity
02 Playable subtractive synth · ADSR · LP filter
03 Import stems directly onto the timeline
04 Mute · solo · pan · gain per track
01 / ENGINE

Web Audio native

Every playback path uses AudioBufferSourceNode, GainNode, StereoPanner, and AnalyserNode. Level meters reflect real signal energy.

02 / OPEN

Open-source separation

Pipeline designed around Demucs and Spleeter. The demo layer is clearly labeled; production models plug in behind the same interface.

03 / FORMATS

WAV · MP3 · FLAC · OGG

Encoders are architected server-side via FFmpeg. WAV export works in-browser today. Others gracefully disable when unavailable.

04 / RUNS ANYWHERE

Cloudflare · VS Code · GitHub

No proprietary lock-in. Frontend deploys to Pages; ML worker runs on any container host. See ARCHITECTURE.md.
